# Project Lizard

Project Lizard skills for the Handshake AI platform.

## Task Families

- **BabyVision (BV)**: Image review, question writing (spatial perception, visual tracking, fine-grained visual discrimination, visual pattern recognition), model response generation, evaluate & rewrite, prompt validation.
- **VQA**: Image review, question writing, model response generation, evaluate & rewrite, prompt validation, stumping strategies.
- **Reviewer Playbook**: QC & audit checklists (BabyVision and VQA), handling LLM Judge feedback, writing strong justifications, reviewer flow and simulation.

## Naming Convention

All Project Lizard skill folders use the `lizard-` prefix to prevent clashes with Project Hedgehog (`handshake-*`) and other platforms.
