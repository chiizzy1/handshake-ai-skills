# Working vocabulary

These definitions support the [operative rules](../../shared-references/canonical-rules.md);
they do not override them.

| Term | Meaning |
|---|---|
| Analytical trap | A plausible reasoning shortcut that produces a materially incorrect result under the supplied evidence and task contract. |
| Bait | Optional evidence that invites a mistaken interpretation for an honest reason, such as a stale summary or a different population. It is not compulsory and must not contain planted false empirical claims. |
| Antidote | Supplied evidence that makes the error discoverable and correctable. It need not be buried or separated from the apparent answer. |
| Arbiter | An applicable definition, date, source hierarchy or other documented rule that resolves a source conflict. |
| Deterministic decision | One defensible recommendation follows from the stated objective, constraints and evidence, allowing equivalent methods and stated ties. |
| Material failure | An error affecting feasibility, recommendation, a substantive supporting result or its interpretation. |
| Local blind screen | A fresh solver receives only the intended prompt and inputs. Record tools, model identity when exposed, hashes and artifacts. |
| Official rollout | Evaluation on the actual platform, using the matched task version and its applicable specification. |
| Gate / flip / confirmation | Optional descriptions of a constraint, ranking-changing correction or apparent corroboration. A task need not contain all three. |

A low score alone does not establish a valid stump: inspect the output, rubric
and golden for substantive errors, invalid grading and alternate valid answers.

For new tasks, Vincent's September 5 announcement requires the **initial
Responses 1 and 2** to average **strictly below 70%**. This is not the best two
scores selected from later runs. Retired strong/weak model tiers and old
thresholds describe historical workflows only. A local pair of fresh contexts
using one inherited model is not evidence from two distinct official models.
