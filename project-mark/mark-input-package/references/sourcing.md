# Sourcing routes

Use original publishers and repository APIs to inspect the actual public
files and their documentation. A starter kit can seed exploration, but it
does not determine the decision, evidence sufficiency or difficulty.

The current shortlist, verified facts and outstanding checks are maintained in
[data selection](../../mark-task-builder/references/data-selection.md).
Read [licensing and provenance](licensing-provenance.md) before fetching.

Prefer a connected body of evidence over unrelated files added to satisfy a
quota. Verify observations, joins, sampling/assignment, timing, outcomes and
missingness. Check that the public files support the proposed analysis.
Do not commit a full task merely because a source is large, famous, obscure,
compressed or accompanied by a paper.

Record discovery, access/rights verification, download, schema inspection,
analytical testing and blind screening as separate stages.
