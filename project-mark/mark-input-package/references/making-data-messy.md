# Data transformations and authentic complexity

Artificial mess is not a requirement. Earlier guidance generalized from a small
number of accepted examples; it did not demonstrate that injecting duplicates,
mojibake or obscure formats improved valid analytical difficulty.

Preserve authentic source structure and document transformations that serve a
real purpose: manageable extracts, stable joins, interoperable formats or
reproducibility. Keep raw downloads and hashes.

Never fabricate empirical evidence, introduce unknowable values, duplicate rows
to meet a count, or hide necessary definitions. A format change must preserve
semantics and load with ordinary tools. Useful challenge comes from connected
analytical requirements whose consequences are tested against the real data.
See [corpus construction](corpus-construction.md).
