# Pipeline

Use the [new-task runbook](new-task-runbook.md) for the current local sequence
and [operative rules](../../shared-references/canonical-rules.md) for task
requirements. The historical twelve-step platform walkthrough is a source
capture; follow the current UI when its fields or order differ.

Local investment order: source inspection → independent analytical prototype →
reasonable-alternative checks → blind screening → complete input package and
official initial-response gate → polished golden deliverables and final checks.

Prototype results, blind screens and official platform outcomes are different
claims. Preserve their evidence and do not substitute one for another.
