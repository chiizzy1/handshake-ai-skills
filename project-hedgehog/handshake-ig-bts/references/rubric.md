## Why This Task Matters

Models learn what "behind the scenes" means from pairs like the ones you build. If the output is only *related* to the input, the model learns the wrong lesson.

So this task measures **scene matching**, not video quality. Almost every rule comes back to one question: does the output show *this exact shot* being made?

## Perspective Framing

The link is not the audio content. Both videos should focus on the same person or content of the scene, from different perspectives.

- **Perspective 1 — input.** The person(s) or setting in the scene, from the POV of a camera. This is the final product.
- **Perspective 2 — output.** The same person(s) or setting in that final-product scene, *while they are actively making it*. It does not include all the editing that went into the final product.

We want to see cameras, lighting, or crew moving objects and props.

Usable output types:

- Making-of footage of that shot being filmed.
- A behind-the-camera angle of that shot.
- The set or camera setup for that shot.
- A before/after of that exact shot.

## What Makes A Valid Pair

A valid pair is **two different real clips of the same moment**. The input is the finished shot; the output is that same shot being made.

| Valid | Not valid |
|---|---|
| **Two distinct clips** — input is the finished shot, output is separate footage of that shot being filmed, with a camera, phone, tripod, crew, lighting, or set visible. The pair only teaches the transformation if the output actually shows the making of the shot. | **Same video twice** — both sides are the same footage, or two trims of one clip with no visible BTS evidence. There is no finished-versus-being-made difference to learn from. Not a low score. Not accepted. |
| **Output is BTS only** — if the source is a split screen, the output is cropped down to just the behind-the-scenes half, so the pair reads as before and after. | **Finished shot still visible** — the crop leaves both halves in frame. The output contains the answer, so it is a side-by-side rather than a transformation. |
| **One contained scene** — both clips stay on a single scene. Multiple BTS moments from one source become up to 3 separate pairs. | **Scene hopping** — the output cuts between several moments or locations. No single description can cover it. |
| **Vertical on both sides** — input and output are both vertical (portrait) IG clips. | **Horizontal clip** — either clip is landscape. It cannot be cropped or padded into the vertical frame. Reject and find another source. |
| **Scoped to the exact shot** — the output shows only the making of the exact moment in the input, same take and same action. | **Shows more or less than the input** — extra takes, unrelated cutaways, or generic set footage from the same shoot. |
| **Real filmed footage** — both clips are live-action video of real people and real places. | **Animated or synthetic** — either clip is animation, CGI, or AI-generated. There is no real filming moment behind it, regardless of quality. |

**Quick test before you submit:** can you point at something in the output that proves the input shot was being filmed, and is everything in the output part of that one shot? If either answer is no, the pair is not valid.

## Related Is Not The Same Moment

This is the single biggest reason pairs get rejected. The BTS clip shows the same subject, same set, or a similar action — but not the literal moment captured in the finished clip.

**None of these qualify:**

- Same dancer, different take.
- Same kitchen, different dish.
- Same movie, different scene.

**Qualifies:** camera, crew, lighting, or rig actively filming the same action, in the same setting, that appears in the finished shot.

**Does not qualify even if related:** a different take of the same routine, a different scene from the same shoot day, general set or prep footage, or the actor before/after filming without capturing the shot itself.

The single check that matters most: you can point to the specific action, line, or beat in the finished clip and see the crew, camera, or rig actively capturing that same action, in the same setting. Being from the same creator's account is not that check.

## The Six Common Errors

1. **Same video for both input and output.** The input and output show the same footage, or two clips with no real finished-versus-being-made difference — for example two trims of one clip labelled as separate videos. *Avoid it:* the output must show visible BTS evidence such as a camera, crew, lighting, rig, or set. Another cut of the finished shot is not enough. This is not a low score, it is not accepted, and repeated instances put your task access at risk.
2. **Split-screen source, cropped badly.** The source is a split screen with the finished shot on one side and the BTS on the other, and the crop leaves both halves visible. *Avoid it:* use Add Crop to isolate only the BTS half. The output must contain only behind-the-scenes footage.
3. **Multiple scenes in one submission.** The output cuts between several different moments or scenes. *Avoid it:* keep each submission to one scene. If a video has multiple BTS moments worth pairing, submit up to 3 separate pairs. Never combine scenes.
4. **Horizontal video orientation.** *Avoid it:* only source vertical (portrait) IG clips for both sides. Horizontal videos must be rejected.
5. **Output shows more (or less) than the input.** The output includes footage or moments that are not part of the exact shot shown in the input — extra takes, unrelated cutaways, or action the input never shows. *Avoid it:* trim out anything beyond what the input actually shows.
6. **Animated or non-real footage.** *Avoid it:* only submit real, live-action video for both sides.

## Do Not Submit

- **A different scene** — BTS of a different scene than the finished clip, even from the same creator or shoot.
- **The same video twice** — a BTS clip with no camera, crew, or rig visible and no real finished-versus-process difference. **Automatic 1/Unacceptable**, not a low score.
- **Input inside the output** — the input video appearing within the output. Crop so only the BTS is submitted.
- **A prompt that doesn't simulate a user** — a prompt that does not simulate a user adding the input video to a model and describing the changes they want.
- **Same topic, no making-of** — two clips that just share a topic or creator without one showing how the other was made.
- **Actor prep footage** — the actor getting ready, even in visibly the same look or outfit. We need BTS of how that exact input clip was created or filmed, not general prep.
- **Generic set footage** — general filming or set footage that does not capture the specific finished shot being made. Real crew and cameras alone are not enough if none of it shows the exact scene. This is a **missing transformation** and should be rejected, not down-rated.

## Cropping One Source Into A Pair

You may crop a video found on Instagram to extract the input and output from the same video. If you do, you must:

- **Keep the output pure BTS.** Remove the finished shot from the output completely. If the output replays the finished shot at all, even briefly before cutting to the crew, camera, or rig, the pair is invalid.
- **Capture the exact actions.** A camera crew, a director, or the same actors in a different movie is not enough. We must see the same scene occurring that we see in the final product.
- **Include only the BTS scene in the output.** Do not include the final product in the output video.
- **Describe audio in the prompt.** Always describe audio differences or sameness in the prompt for every task in this project, even when not cropping. With cropped videos the audio will be the same for both input and output — you must still describe this.
- **Review video quality.** Resolution must be at least 720px after cropping.
- **Submit at most 3 pairs from the same video.** If a video has multiple BTS + final-product pairs, choose the best 3 scenes and use 3 different submissions. Never add multiple scenes to one submission.

## Hard Requirements

- **Length** — at least 5 seconds per clip after trimming, and at most 16 seconds total (source + result combined).
- **One video** — the final assistant turn must contain exactly one video.
- **Same shot** — the result must show the making of this source (the same shot or scene), not a generic or different-scene clip.
- **Clarity** — both clips must be clear enough to recognise the shared shot. No unusable, fully obscured clips.
- **No third-party watermarks** — *fine:* a creator's @handle or username, or a brand shown in the scene. Try to crop caption or username text where you can without hurting video quality; if you cannot, usernames are OK. *Not OK:* a moving TikTok or YouTube logo with username, a tiled Shutterstock/Getty/Alamy/iStock overlay, another app's export mark, or text placed over an important part of the video such as actors' faces.
- **Prompt** — at least 20 words describing the behind-the-scenes relationship. Simulate a user asking a model to give them the output based on the input provided, covering what changed and what stayed the same.

## Grading Rubric 1-5

- **5 Exceptional** — the result clearly shows how this exact finished video was made: the same shot or scene, recognisable finished versus being made. High quality and informative. The shots line up temporally. The prompt fully describes the behind-the-scenes relationship.
- **4 Strong** — a genuine behind-the-scenes of this finished clip, good quality. The shots line up. The prompt describes it but may be slightly vague.
- **3 Acceptable** — a valid behind-the-scenes of the source, but unremarkable or only loosely informative. The prompt connects them but is vague.
- **2 Weak** — any one of: quality problems (blurry or unclear); a different scene from the same creator or shoot rather than the same shot; no real finished-versus-process difference; the prompt misses it; or under 5s of lined-up overlap.
- **1 Unacceptable** — unrelated or disjointed, or not actually behind-the-scenes of this clip. The result is a standalone clip or a duplicate. The prompt is missing or does not make logical sense.

## Worked Examples

**Good — same scene, from behind the camera.** A dance reel paired with a wider view of the room, all four women in matching black outfits practising the routine and adjusting positions, with a phone mounted on a tripod clearly visible at the front, recording the dance.

> "Create behind-the-scenes footage showing how this dance reel was filmed. Use a wider view of the room with all four women in matching black outfits getting ready to perform. They are practicing the routine, adjusting their positions, and laughing between takes. A phone mounted on a tripod is clearly visible at the front, recording the dance. In the background, keep the grey sofa and open living area of the apartment visible. Keep the white 'BTS' text at the top center throughout the video."

**Good — clearly the same scene being made.** Both clips start when the dancers' hands are raised facing each other, then move to leg movement; the output additionally shows a lighting stand and a videographer holding equipment while the dancers perform.

**Good — behind the scenes of the exact shot.** The same dance filmed from a different angle on the left side, the girl performing the same steps with the background dancers, including a specific timestamped detail (dropping a black scarf at 0:17) and described background audio.

**Bad — same setup, not the same scene.** A finished clip paired with a BTS-style clip of the same performers in a different moment. The description is detailed and the pair still fails, because the output is not the making of *this* shot.

**Bad — reaction, not making-of.** A green-screen overlay clip where a creator criticises and mocks the input's commentary. That is a reaction, which belongs to a different task entirely.

**Bad — same movie, not the same exact scene.** A spaceship scene paired with detailed BTS of puppeteers and rigs from the same production but a different shot. Same film and genuine BTS footage are not enough.

## Drills

Seven real submissions; six were rejected and one passed. The requirement each one breaks:

1. **Landscape candidate, everything else usable** — horizontal clips are rejected outright. Find a vertical source. Cropping it down to vertical is not the fix.
2. **Vertical, real footage, cuts between several shots** — every camera cut counts as a new scene, so this covers multiple scenes. Being from one shoot does not make the cuts acceptable.
3. **Vertical, one scene, but AI-generated** — AI-generated footage is not allowed. Both clips must be real. Noting it in a comment does not help.
4. **Cuts between several shots and the BTS side is a picture-in-picture inset** — fails on both counts: multiple scenes and an inset rather than a full BTS frame.
5. **Vertical, real, one scene, but the audio starts partway through a lyric** — the trim does not land on a clean boundary. Muting the audio is not the fix.
6. **A sliver of the other video still visible at the edge of each cropped clip** — leftover footage from the other clip means the crop is wrong. A thin strip is not close enough, and reviewers do check the edges.
7. **Passes** — the output shows how this exact shot was made, the same dance beat and audio appear in both, the green screen and tracking markers are revealed, nothing blocks the important part of the frame, and there is no watermark. Revealing the green screen and markers is the point, not a problem. Shared audio in both clips does not make it the same video twice.

## Knowledge Check Answers

- **Same performer, same outfit, same subway station, but a different run-through with different moves** → not valid. A different take with different moves is not the same moment, even with the same performer and location.
- **Which single check matters most for confirming the same scene?** → you can point to the specific action, line, or beat in the finished clip and see the crew, camera, or rig actively capturing that same action, in the same setting.
- **Input and output visually identical, no camera/crew/rig in the output, just a different trim, rated 4/5 because "the clips line up perfectly"** → should have been an automatic 1/Unacceptable. There is no finished-versus-being-made distinction, so trim and alignment quality are irrelevant.
- **Real crew, cameras, and lighting rigs on the actual set, but no footage of the specific finished shot being filmed** → not acceptable. This is a missing transformation. Real crew and equipment on set are not enough if they do not capture the actual shot being filmed.

## Final Checklist

1. Matched the exact scene — not just a similar setup, movie, or creator.
2. Input video is not included inside the output.
3. Audio sameness or difference is described in the prompt.
4. Resolution checked — at least 720px after any crop.
5. Prompt is 20+ words and simulates a real model request.
6. Watermark check done — no third-party logos or overlays.
7. Length limits respected — 5s+ per clip, 16s total max, exactly one video in the final turn.
8. No more than 3 submissions pulled from the same source video.
