# Cheat Sheet

**Submit evidence, not a verdict**

- Your explanation is required, but **there is no character target.**
- Name something visible and state how it affected the comparison.
- **Do not spend words repeating which response won.**
- For a tie, name the concrete similarity or shared defect. If both fail, state why their severity is equivalent.
- Use Skip when tooling or language prevents inspection. Skip then overrides every rating and Submit.
- **Exception, do not Skip:** a response that loads as blank is observable output. Rate it.
- If you understand the primary requirement and can evaluate both responses, rate normally even when secondary text is unfamiliar.
- Use Skip when a safety notice shown in the task, or task-owner guidance given before the session, says not to inspect or rate the content.
- When both responses visibly fail, compare severity. Prefer the less severe failure; use Tie only when severity is equivalent.
- Do not use Skip merely because the comparison is close or difficult.

**Voice input and translation**

- Choose the rating first, then record the explanation. Voice input is required by default.
- You may speak in your native language. Muse automatically transcribes and translates your explanation into English.
- If no microphone is detected, the "I don't have a microphone" option appears; select it to unlock typing. Some browsers can confirm this only after you press Start voice input.
- A microphone or transcription error does not unlock typing automatically; retry or use the explicit no-microphone option.
- Review and correct the confirmed English explanation before submitting.
- **The confirmed text is final.** Correct any transcription or translation error before submitting.
